├─────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                      │
│  ┌────────────────────────────────────────────────────────────────────────────────┐ │
│  │  STEP 1: LOAD DATASET                                                         │ │
│  │  ┌──────────────────────────────────────────────────────────────────────────┐ │ │
│  │  │  data = load_dataset('gnss_5g_dataset.pkl')                             │ │ │
│  │  │                                                                          │ │ │
│  │  │  Input: features (N×11), labels (N×3)                                   │ │ │
│  │  │  Features: [distance, bs_index, pos_x, pos_y, pos_z,                    │ │ │
│  │  │             vel_x, vel_y, vel_z, time_norm, sin_time, cos_time]        │ │ │
│  │  │  Labels: [sigma_toa, sigma_azimuth, sigma_elevation]                    │ │ │
│  │  └──────────────────────────────────────────────────────────────────────────┘ │ │
│  └────────────────────────────────────────────────────────────────────────────────┘ │
│                                          │                                           │
│                                          ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────────┐ │
│  │  STEP 2: XGBOOST TRAINING                                                     │ │
│  │  ┌──────────────────────────────────────────────────────────────────────────┐ │ │
│  │  │  X_scaled = (X - mean) / std      # Feature Normalization               │ │ │
│  │  │                                                                          │ │ │
│  │  │  For each output j ∈ {TOA, Azimuth, Elevation}:                         │ │ │
│  │  │  ┌────────────────────────────────────────────────────────────────────┐  │ │ │
│  │  │  │  Objective: L(θⱼ) = Σᵢ (yᵢ - ŷᵢ)² + Σₖ Ω(fₖ)                    │  │ │ │
│  │  │  │                                                                     │  │ │ │
│  │  │  │  Where: ŷᵢ = Prediction, Ω(f) = γT + ½λ||w||²                     │  │ │ │
│  │  │  │         T = number of leaves, w = leaf weights                      │  │ │ │
│  │  │  │                                                                     │  │ │ │
│  │  │  │  Update Rule: ŷᵢ^(t) = ŷᵢ^(t-1) + η·fₜ(xᵢ)                        │  │ │ │
│  │  │  │  Where: η = learning rate (0.1), fₜ = t-th decision tree            │  │ │ │
│  │  │  └────────────────────────────────────────────────────────────────────┘  │ │ │
│  │  │                                                                          │ │ │
│  │  │  Model Parameters:                                                        │ │ │
│  │  │  - n_estimators = 100  (number of trees)                                │ │ │
│  │  │  - max_depth = 6       (maximum tree depth)                             │ │ │
│  │  │  - learning_rate = 0.1 (step size)                                      │ │ │
│  │  │  - objective = 'reg:squarederror' (regression)                         │ │ │
│  │  └──────────────────────────────────────────────────────────────────────────┘ │ │
│  └────────────────────────────────────────────────────────────────────────────────┘ │
│                                          │                                           │
│                                          ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────────┐ │
│  │  STEP 3: SYSTEM INITIALIZATION                                                 │ │
│  │  ┌──────────────────────────────────────────────────────────────────────────┐ │ │
│  │  │  State Vector: x = [x, y, z, vx, vy, vz, ρ, φ]ᵀ ∈ ℝ⁸                    │ │ │
│  │  │                                                                          │ │ │
│  │  │  Initial State: x₀ = [0, 0, 0, 0, 0, 0, 0, 0]ᵀ                          │ │ │
│  │  │                                                                          │ │ │
│  │  │  Initial Covariance: P₀ = diag([100, 100, 100, 10, 10, 10, 1e-6, 1e-6]) │ │ │
│  │  │                                                                          │ │ │
│  │  │  System Parameters:                                                       │ │ │
│  │  │  - K = 4 BSs, M = 9 Satellites                                           │ │ │
│  │  │  - μ_BS = 10 Hz, μ_Sat = 1 Hz                                            │ │ │
│  │  │  - R_a = μ_BS / μ_Sat = 10 (rate ratio)                                 │ │ │
│  │  │  - n_PL = 1.98 (path loss exponent)                                      │ │ │
│  │  │  - σ_v = 3.0 m/s, σ_eps = 63e-6 s/s                                    │ │ │
│  │  └──────────────────────────────────────────────────────────────────────────┘ │ │
│  └────────────────────────────────────────────────────────────────────────────────┘ │
│                                          │                                           │
│                                          ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────────┐ │
│  │  STEP 4: CALIBRATION (Mathematical Model)                                     │ │
│  │  ┌──────────────────────────────────────────────────────────────────────────┐ │ │
│  │  │  For each BS k and position p:                                           │ │ │
│  │  │  d = √((x - x_k)² + (y - y_k)² + (z - z_k)²)                           │ │ │
│  │  │                                                                          │ │ │
│  │  │  σ = 1e-8 × d^(n_PL)                                                    │ │ │
│  │  │                                                                          │ │ │
│  │  │  CRLB₀ = mean(σ² / d^(n_PL))                                            │ │ │
│  │  │                                                                          │ │ │
│  │  │  Formula: CRLB₀ = (1/N) × Σ (σ² / d^(n_PL))                            │ │ │
│  │  └──────────────────────────────────────────────────────────────────────────┘ │ │
│  └────────────────────────────────────────────────────────────────────────────────┘ │
│                                          │                                           │
│                                          ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────────┐ │
│  │  STEP 5: AI-ENHANCED MRAKF (Multi-Rate Adaptive Kalman Filter)               │ │
│  │                                                                                 │ │
│  │  For each epoch n = 1 to N (N = number of GNSS epochs):                       │ │
│  │  ┌──────────────────────────────────────────────────────────────────────────┐ │ │
│  │  │  STAGE 1: FIRST-STAGE EKF (High Rate - 10 Hz)                          │ │ │
│  │  │                                                                          │ │ │
│  │  │  For i = 1 to R_a (R_a = μ_BS/μ_Sat = 10):                              │ │ │
│  │  │  ┌────────────────────────────────────────────────────────────────────┐ │ │ │
│  │  │  │  a) PREDICTION                                                     │ │ │ │
│  │  │  │  ───────────────────────────────────────────────────────────────── │ │ │ │
│  │  │  │  F = State Transition Matrix with Δt = 1/μ_BS = 0.1s              │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  F = [I₃ₓ₃    Δt·I₃ₓ₃    0₃ₓ₂]                                   │ │ │ │
│  │  │  │      [0₃ₓ₃    I₃ₓ₃       0₃ₓ₂]                                   │ │ │ │
│  │  │  │      [0₂ₓ₃    0₂ₓ₃       F_clock]                                 │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  F_clock = [1  Δt]                                                 │ │ │ │
│  │  │  │            [0  1 ]                                                 │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  x̂⁻ = F · x̂_{prev}     (State Prediction)                        │ │ │ │
│  │  │  │  P⁻ = F · P · Fᵀ + Q   (Covariance Prediction)                    │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  Q = Process Noise Covariance:                                     │ │ │ │
│  │  │  │  Q = [σᵥ²·Δt³/3·I₃ₓ₃    σᵥ²·Δt²/2·I₃ₓ₃    0₃ₓ₂]                 │ │ │ │
│  │  │  │      [σᵥ²·Δt²/2·I₃ₓ₃    σᵥ²·Δt·I₃ₓ₃       0₃ₓ₂]                 │ │ │ │
│  │  │  │      [0₂ₓ₃              0₂ₓ₃              Q_clock]                 │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  b) AI NOISE PREDICTION (XGBoost)                                  │ │ │ │
│  │  │  │  ───────────────────────────────────────────────────────────────── │ │ │ │
│  │  │  │  For each BS k:                                                    │ │ │ │
│  │  │  │  Extract features:                                                 │ │ │ │
│  │  │  │  f_k = [d_k, k, x, y, z, vx, vy, vz, t/T, sin(2πt/T), cos(2πt/T)]│ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  [σ_TOA, σ_Az, σ_El] = XGBoost_Predict(f_k)                      │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  R_k = diag([σ_TOA², σ_Az², σ_El²])                              │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  R_BS = blkdiag(R₁, R₂, ..., R_K)                                 │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  c) KALMAN GAIN                                                    │ │ │ │
│  │  │  │  ───────────────────────────────────────────────────────────────── │ │ │ │
│  │  │  │  H = Jacobian of h_BS with respect to x                           │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  S = H · P⁻ · Hᵀ + R_BS   (Innovation Covariance)                │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  K = P⁻ · Hᵀ · S⁻¹         (Kalman Gain)                         │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  d) UPDATE                                                        │ │ │ │
│  │  │  │  ───────────────────────────────────────────────────────────────── │ │ │ │
│  │  │  │  ỹ = y_BS - h_BS(x̂⁻)    (Innovation)                             │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  x̂⁺ = x̂⁻ + K · ỹ        (State Update)                          │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  P⁺ = (I - K · H) · P⁻    (Covariance Update)                    │ │ │ │
│  │  │  └────────────────────────────────────────────────────────────────────┘ │ │ │
│  │  └──────────────────────────────────────────────────────────────────────────┘ │ │
│  │                                                                                 │ │
│  │  ┌──────────────────────────────────────────────────────────────────────────┐ │ │
│  │  │  STAGE 2: SECOND-STAGE EKF (Low Rate - 1 Hz)                           │ │ │
│  │  │                                                                          │ │ │
│  │  │  x̂⁻ = x̂⁺ (from Stage 1)                                                │ │ │
│  │  │  P⁻ = P⁺ (from Stage 1)                                                │ │ │
│  │  │                                                                          │ │ │
│  │  │  For each satellite m = 1 to M (M = 9):                                 │ │ │
│  │  │  ┌────────────────────────────────────────────────────────────────────┐ │ │ │
│  │  │  │  a) JACOBIAN                                                       │ │ │ │
│  │  │  │  ───────────────────────────────────────────────────────────────── │ │ │ │
│  │  │  │  H_m = ∂h_Sat_m/∂x                                                │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  ∂h_Sat/∂x = (x - x_sat)/(c·d)                                    │ │ │ │
│  │  │  │  ∂h_Sat/∂y = (y - y_sat)/(c·d)                                    │ │ │ │
│  │  │  │  ∂h_Sat/∂z = (z - z_sat)/(c·d)                                    │ │ │ │
│  │  │  │  ∂h_Sat/∂ρ = 1                                                    │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  b) INNOVATION COVARIANCE                                          │ │ │ │
│  │  │  │  ───────────────────────────────────────────────────────────────── │ │ │ │
│  │  │  │  S_m = H_m · P⁻ · H_mᵀ + R_Sat_m                                 │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  c) KALMAN GAIN                                                    │ │ │ │
│  │  │  │  ───────────────────────────────────────────────────────────────── │ │ │ │
│  │  │  │  K_m = P⁻ · H_mᵀ / S_m                                            │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  d) SEQUENTIAL UPDATE                                              │ │ │ │
│  │  │  │  ───────────────────────────────────────────────────────────────── │ │ │ │
│  │  │  │  ỹ_m = y_Sat_m - h_Sat_m(x̂⁻)                                     │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  x̂ = x̂ + K_m · ỹ_m                                              │ │ │ │
│  │  │  │                                                                     │ │ │ │
│  │  │  │  P = (I - K_m · H_m) · P⁻                                         │ │ │ │
│  │  │  └────────────────────────────────────────────────────────────────────┘ │ │ │
│  │  └──────────────────────────────────────────────────────────────────────────┘ │ │
│  └────────────────────────────────────────────────────────────────────────────────┘ │
│                                          │                                           │
│                                          ▼                                           │
│  ┌────────────────────────────────────────────────────────────────────────────────┐ │
│  │  STEP 6: ERROR CALCULATION                                                    │ │
│  │  ┌──────────────────────────────────────────────────────────────────────────┐ │ │
│  │  │  e_k = √((x̂_k - x_true_k)² + (ŷ_k - y_true_k)² + (ẑ_k - z_true_k)²)   │ │ │
│  │  │                                                                          │ │ │
│  │  │  Mean Error: ē = (1/N) · Σ_{k=1}^N e_k                                 │ │ │
│  │  │                                                                          │ │ │
│  │  │  RMSE: RMSE = √((1/N) · Σ_{k=1}^N e_k²)                                │ │ │
│  │  │                                                                          │ │ │
│  │  │  Max Error: e_max = max(e₁, e₂, ..., e_N)                              │ │ │
│  │  │                                                                          │ │ │
│  │  │  95th Percentile: e_95 = 95th percentile of sorted errors               │ │ │
│  │  │                                                                          │ │ │
│  │  │  Improvement: I = ((ē_std - ē_ai) / ē_std) × 100%                    │ │ │
